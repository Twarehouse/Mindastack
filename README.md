# MINDA GUI ROBOT FRONTEND

React + Vite + Tailwind + Electron project packed in electron 

## How to run

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start dev server: This allows to run program on other devices as well.
   ```bash
   npm run dev -- --host
   ```

3. Open the URL shown (usually http://localhost:5173)
